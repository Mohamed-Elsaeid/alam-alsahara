# عالم الصحراء — Alam AlSahara

صفحة روابط بسيطة ومتجاوبة مع الوضع الفاتح والداكن، بالعربية والإنجليزية.

## تعديل البيانات

- عدّل الاسم والوصف ورابط الموقع وروابط السوشيال في `profile.json`.
- استبدل `logo.png` لتغيير الشعار.
- التصميم في `style.css`، والتفاعلات في `app.js`، واختيار الوضع في `theme-init.js`.
- لا تحتاج الصفحة إلى تثبيت مكتبات أو خطوة بناء.

## التشغيل

ارفع الملفات كما هي إلى استضافة صفحات ثابتة، أو شغّل خادمًا محليًا من مجلد المشروع:

```sh
python -m http.server 8000
```

ثم افتح `http://localhost:8000`.

## الصفحة المنشورة

https://mohamed-elsaeid.github.io/alam-alsahara/

النشر التلقائي مفعّل من الفرع `main`، مجلد الجذر. تحديث ملفات الصفحة على هذا الفرع يحدّث النسخة المنشورة بعد اكتمال النشر.

زر الموقع الرسمي يفتح https://alamalsahara.com، وروابط السوشيال محفوظة كما هي.

رمز QR منفصل عن الصفحة. استخدم QR الموجّه للرابط الجديد أعلاه.
