# عالم الصحراء — Alam AlSahara

صفحة روابط بسيطة ومتجاوبة مع الوضع الفاتح والداكن، بالعربية والإنجليزية.

## تعديل البيانات

- عدّل الاسم والوصف ورابط الموقع وروابط السوشيال في `profile.json`.
- استبدل `logo.png` لتغيير الشعار.
- التصميم في `style.css`، والتفاعلات في `app.js`، واختيار الوضع في `theme-init.js`.
- لا تحتاج الصفحة إلى تثبيت مكتبات أو خطوة بناء.

## التشغيل

ارفع الملفات كما هي إلى استضافة صفحات ثابتة، أو شغّل خادمًا محليًا من مجلد المشروع:

```sh
python -m http.server 8000
```

ثم افتح `http://localhost:8000`.

## GitHub Pages

من إعدادات المستودع اختر **Pages → Deploy from a branch**، ثم الفرع الأساسي ومجلد **/(root)**، إذا كانت الخدمة متاحة لنوع الحساب والمستودع.

النسخة المنشورة حاليًا:
https://alam-alsahara-connect-eg.nicestingray.chatgpt.site/

زر الموقع الرسمي يفتح:
https://alamalsahara.com

حفظ الملفات على GitHub وحده لا يغيّر الموقع المنشور حاليًا تلقائيًا. عند الانتقال إلى رابط استضافة جديد، حدّث canonical وog:image في `index.html` وأنشئ QR للرابط الجديد. رمز QR الحالي يفتح النسخة المنشورة أعلاه، وهو غير مضاف للصفحة.
